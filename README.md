# The GPS Swears It Was a Shortcut

A one-line excuse, in the GPS's own smug and defensive voice, for
sending the driver down the wrong road — written for the
[make.fun competition](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

The GPS denies everything, blames a map that promised a lake had a
bridge in 2019, and stands by that promise with total confidence —
right up until the driver's tires get wet.

## Run

```sh
python3 main.py
```

Writes the single-line entry (at most 200 characters, plain UTF-8
text) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to redirect
the output directory for local verification.
